# Eric 的工具箱

個人首頁，只給自己用：左側選工具，右側直接使用。發布在 https://ericlau1107.github.io/ （GitHub Pages）。

- **加工具**：在 `index.html` 的 `TOOLS` 清單加一筆。工具最好放在本倉庫的子資料夾（同一個網址底下），嵌入時瀏覽器才不會把資料分開存。
- **勞報單產生器**（`labor-report/`）：由另一個私人倉庫建置公開版後同步過來，指令是 `sh tools/sync-labor-report.sh`。同步腳本會確認公開版不含任何預填資料才放行。
- **案務專案工作台**（`#project-desk`）：從工具箱開啟既有私人 Sites 工作台，需登入原本的 ChatGPT 帳號。登入與 D1 資料保存由工作台提供；GitHub Pages 只提供公開入口，不複製案件資料或後端程式。`TOOLS` 設定 `mode: 'external'` 的工具以新分頁連結開啟。
- **個人記帳／收支日常**（`money-report/`）：可直接新增收支、退款、帳戶轉帳，管理存款與負債，支援 24 種幣別的外幣帳戶與原幣記帳、雙邊實收轉帳；資產以每日公開參考價換算 TWD，歷史收支保留各筆入帳匯率。可查詢原幣歷史餘額（外幣估值使用目前參考價）與資產、每月分析、消費分佈及預算；JSON 完整備份/還原、CSV 匯出。初始帳本為空，帳目只存在該裝置瀏覽器 IndexedDB，沒有銀行連線或跨裝置同步。匯率來源為 ExchangeRate-API 每日公開價，非銀行即時成交價；只請求固定公開 TWD 報價 URL，不傳帳戶或金額。主頁 CSP 僅放行該端點，月報檢視器仍禁止網路連線。原本月報檢視器保留在 `money-report/report-viewer.html`，沿用既有匯入資料。原始碼在 `Dev/systems/money-report/`，以 `sh tools/sync-toolbox.sh` 同步兩個 HTML；只發布程式與經守門的虛構月報樣本。
- **健康與健身／日日動**（`health-fitness/`）：手動健康日誌、可保存的 30 天月計畫與每日起步課表、依當日健身課表與目標連動三餐、可選訓練時間及運動前後餐食／過敏篩選／睡眠時段規劃、實際生活紀錄、重量組次與訓練進度、JSON 備份/還原及 CSV 匯出。初始資料空白，只存在該瀏覽器 IndexedDB；没有穿戴裝置、醫療院所或 AI API 串接。原始碼在 `Dev/systems/health-fitness/`，以 `sh tools/sync-toolbox.sh` 同步公開 HTML。
- **出班器材檢查表**（`gear/`，接案工具）：依班型的器材清單，出發前與歸還時各勾一次。資料只存瀏覽器，可下載 JSON 備份。
- **拍攝日通告**（`callsheet/`，接案工具）：集合時間、日出日落、聯絡人與當天流程，整理成一張通告。資料只存瀏覽器，可下載備份。
- **到期日管家**（`expiry/`，生活）：證件、保險、訂閱的到期日與提醒。資料只存瀏覽器，可下載備份。
- **語言每日複習**（`study/`，生活）：日・韓・英單字卡，每天複習到期的卡。資料只存瀏覽器，可下載備份。
- **每週回顧**（`weekly/`，生活）：每週彙整花費、運動與到期事項（只讀其他工具的資料）；只有自己的週記寫備份紀錄。
- **資料保險箱**（`vault/`，工具箱「資料」分類）：瀏覽器可能清掉這個網站的資料（Safari 7 天沒用、空間不足、手動清除），所以這一頁顯示三件事：持久保存是否啟用（按鈕才呼叫 `navigator.storage.persist()`）、已用空間，以及 8 個會寫備份紀錄的工具各自的備份狀態（有沒有資料、上次備份幾天前）。**提醒只看一件事**：該工具的備份紀錄寫著 `hasData:true`，而且 `lastBackupAt` 是空的或超過 14 天前，才會被框起來、才會算進首頁提醒條。沒有紀錄的工具顯示「還沒有紀錄：打開這個工具存一次資料或做一次備份就會出現」，不提醒、不猜；紀錄寫著 `hasData:false` 的顯示「沒有資料」，同樣不提醒。頁面只讀下面的「備份紀錄約定」，**不讀任何工具的內容、不碰任何資料庫（沒有 `indexedDB` 呼叫）**，CSP 為 `connect-src 'none'`。判斷規則集中在 `vault/status.js`（資料保險箱頁與首頁共用）。首頁另有「提醒條」：「有 N 個工具該備份了」，按「今天不再提醒」當天不再出現（隔天恢復）。
- **注意**：本倉庫和網頁都是公開的，只放本身公開、不含個資的工具。`robots.txt` 擋搜尋引擎爬每個工具資料夾（`labor-report/`、`money-report/`、`health-fitness/`、`gear/`、`callsheet/`、`expiry/`、`study/`、`weekly/`、`vault/`），作品集（`/portfolio/`）不擋；首頁本身帶 noindex。
- **同網域規則（不可動）**：這個網域（含 `/portfolio/`、`/ledger-house/` 等其他倉庫的 Pages）所有頁面共用同一個 origin，任何一頁執行的程式都讀得到記帳月報、勞報單存在瀏覽器裡的資料。所以**網域上的頁面只能執行自己的程式；外部程式必須鎖定版本＋SRI，永遠不放廣告或追蹤程式**。推上 main 前跑 `python3 tools/check-scripts.py`。
- **作品集網站**（`#portfolio`）：另一個公開倉庫 `ericlau1107/portfolio` 的 GitHub Pages，網址 https://ericlau1107.github.io/portfolio/。跟工具箱同一個網址底下，所以直接嵌在右側；內容更新在作品集那邊發布（`~/Desktop/03_作品集/網站/_publish-pages.sh`），工具箱不用跟著改。
- `ledger-house/` 是另一個倉庫（記帳小屋）的 GitHub Pages，不在本倉庫。

## 備份紀錄約定（各工具寫、資料保險箱讀）

只放「狀態」，永遠不放任何內容（姓名、金額、健康數值都不行）。

- **localStorage 鍵**：`toolbox.backup.v1`
- **格式**：`{"v":1,"tools":{"<toolId>":{"hasData":布林,"updatedAt":"ISO 8601","lastBackupAt":"ISO 8601 或 null"}}}`
- **toolId**：`labor-report`（勞報單）、`money-report`（個人記帳）、`health-fitness`（健康與健身）、`gear`（出班器材檢查表）、`callsheet`（拍攝日通告）、`expiry`（到期日管家）、`study`（語言每日複習）、`weekly`（每週回顧，只寫自己的週記）
- **誰寫**：各工具自己，用工具內一小段獨立的 `markToolbox(patch)`（不共用檔案、永遠不丟錯、不擋工具自己的儲存）。時機：
  1. 成功儲存真實使用者資料後 → `{hasData:true, updatedAt:現在}`（記憶體內節流，60 秒最多一次；載入後第一次儲存一定寫）
  2. 工具自己的「全部刪除／重設」完成後 → `{hasData:false, updatedAt:現在, lastBackupAt:null}`（2026-10-13 起 `lastBackupAt` 一併清成 `null`：重設前的舊備份檔不涵蓋重設後才輸入的資料，所以不能讓「上次備份」繼續顯示成有備份、也不能讓提醒靜音）
  3. 使用者下載該工具的 JSON 備份時 → `{lastBackupAt:現在}`。**從備份檔還原成功後**（2026-10-13 起）→ 工具**立刻**更新自己的紀錄（不必重新整理、不等 60 秒節流）：`hasData` 照還原後實際的內容、`updatedAt` 現在；`lastBackupAt` 以該工具畫面上顯示的「最近備份」為準，讓資料保險箱和首頁提醒跟工具自己顯示的一致（備份時間只存在紀錄裡的工具維持原值；自己另存備份時間的工具，紀錄跟著它走）
  4. **每次載入頁面時**（2026-10-12 新增）：工具已經有使用者資料，但紀錄寫 `hasData:false` 或根本沒有紀錄 → 補寫 `hasData:true`（原本有 `updatedAt` 就保留，沒有才用現在）。紀錄絕不能宣稱工具沒有的資料；反過來，只是打開工具、沒存過資料，就不寫 `hasData:true`。
- **誰讀**：只有 `vault/status.js`（資料保險箱頁與首頁提醒條共用）。**只看紀錄，不猜**：沒有紀錄的工具顯示「還沒有紀錄」，不提醒；不看資料庫名稱、不看其他 localStorage 鍵，**絕不呼叫任何 `indexedDB` 方法**（開一個不存在的資料庫會把它建出來，弄壞工具自己的升級；而且「打開過工具」會建出空資料庫，不代表有資料）。
- **提醒規則**：只算紀錄寫著 `hasData:true` 的工具，且 `lastBackupAt` 是空的、超過 14 天前（以當地日曆日計算），或比現在晚 5 分鐘以上（標成「時間異常」，通常是裝置時間曾被調過，同樣算該備份）。`hasData:false` 或沒有紀錄一律不提醒。
- 首頁另存一個只給自己用的小鍵 `toolbox.vault.skipDay`（「今天不再提醒」的日期），不屬於約定。
